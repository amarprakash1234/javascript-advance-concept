## 📌 About This Repository

Welcome to my Advanced JavaScript repository!

This repository contains code examples, experiments, and practice exercises focused on understanding JavaScript beyond the basics.

My goal is to understand how JavaScript behaves under the hood, how asynchronous operations work, and how to write cleaner, more predictable, and maintainable code.

The examples help me strengthen my JavaScript fundamentals for frontend development, backend development with Node.js, and technical interviews.

## 📚 Topics Covered

### 🧩 Core JavaScript

- Scope and lexical scope
- Hoisting
- Execution context
- The `this` keyword
- Functions and higher-order functions
- Closures
- Callbacks
- Prototypes and prototypal inheritance

### ⚡ Asynchronous JavaScript

- Callback functions
- Promises
- Promise chaining
- `async` and `await`
- Error handling with asynchronous code
- Event loop
- Call stack and task queues
- Microtasks and macrotasks

### 🛠️ Modern JavaScript (ES6+)

- Arrow functions
- Template literals
- Destructuring
- Spread and rest operators
- Modules and imports
- Classes
- Optional chaining
- Nullish coalescing

### 🔍 Deeper JavaScript Concepts

- Primitive and reference types
- Shallow copy vs. deep copy
- Pass-by-value behavior
- Event bubbling and capturing
- Debouncing and throttling
- Memory management and garbage collection

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- A code editor such as Visual Studio Code

### 1. Clone the Repository

```bash id="3k7c9v"
git clone https://github.com/amarprakash1234/javascript-advance-concept.git
```

### 2. Navigate to the Repository

```bash id="g5k3qt"
cd javascript-advance-concept
```

### 3. Run an Example

If an example is a standalone JavaScript file, execute it with Node.js:

```bash id="b8t2mm"
node filename.js
```

Replace `filename.js` with the actual file you want to run.

Some examples involving browser APIs, the DOM, or user interface events need to run in a web browser instead.

## 💡 How to Use This Repository
